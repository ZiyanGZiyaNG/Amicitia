提示：本頁使用 Google 地圖的 iframe 內嵌（免 API 金鑰）來搜尋附近的羽球場地；實際結果取決於 Google 地圖的資料收錄情況。

ℹ️ 使用說明

  • 先在「我的面板」填寫資料並按下「儲存 / 套用」。
  • 按「重新偵測位置」授權定位（需在 HTTPS 網站），或使用預設位置。
  • 調整「距離門檻」後，系統會找出 N 公尺 內最適合的對手（依 排位、勝率、戰力分、距離計分）。
  • 在候選清單按「開賽」可將雙方帶入下方的 3戰2勝記分板，並於每分制下記錄比數與局數。
  • 右側地圖以 iframe 內嵌方式搜尋「羽球館」等關鍵字，無需任何 API 金鑰。
  • 記分板即時統計：顯示「總比分（累計各局＋當前局）」與「戰力」。戰力計算：以註冊戰力為基礎 基礎戰力（註冊） + (自己得分 / 該局總得分 × 100 − 50)；下限 0；每局（最多三局）結束會記錄本局戰力並顯示已完局的平均值。
